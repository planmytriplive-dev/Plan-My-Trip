# Destination photography checklist

The homepage currently uses lightweight CSS color placeholders. Replace each one with original, licensed photography supplied for Plan My Trip. Do not use watermarked images or generic stock. Keep originals outside `public`, export optimized AVIF/WebP versions into `public/assets/`, and render them with `next/image` using responsive `sizes` and accurate alt text.

## Required shots

- **Katra & Vaishno Devi:** Katra town/base camp at blue hour; approach to the Bhawan or yatra route (respectful, no staged worship); local team or guesthouse detail.
- **Srinagar:** Dal Lake at early morning; shikara or houseboat detail with people only when consent is available; Mughal garden or old-city street.
- **Gulmarg:** meadow in summer; gondola/mountain panorama in clear conditions; winter snow scene if winter itineraries are offered.
- **Pahalgam:** Lidder river valley; pine landscape; village or local hospitality detail.
- **Sonamarg:** Sindh river valley; high meadow and mountain panorama; seasonal road/landscape context.
- **Cross-destination editorial:** one wide Kashmir landscape for the hero; one portrait of the local team; one planning/hospitality detail; a small gallery set for each package route.

## Delivery notes

Supply horizontal hero and card crops, plus portrait crops for mobile layouts. Include photographer/usage credit, location, season, capture date, and alt-text suggestion with each file. Keep source filenames descriptive (for example `srinagar-dal-lake-morning.webp`). Do not add ratings, people, or landmarks that cannot be verified from the supplied originals.
